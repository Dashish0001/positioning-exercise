# Positioning Exercise

A responsive product showcase built using HTML5 and CSS3 as part of The Odin Project.

## Features

- CSS Grid responsive product layout
- Relative positioning
- Absolute positioning
- Fixed floating cart button
- Sticky page heading
- SVG product illustrations
- Hover effects and transitions
- Responsive design for desktop, tablet and mobile

## Technologies

- HTML5
- CSS3
- SVG
